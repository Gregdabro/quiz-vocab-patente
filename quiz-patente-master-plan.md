## 3. Архитектура учебного блока

### Блок для Типа A (знаковые темы)

**Атомарная единица = ЗНАК, не вопрос.**

```
Знак (изображение)
  ├── ~12 вопросов (min 5, max 28)
  ├── 8–12 ключевых слов
  └── semantic_group (categoria знака)

Блок из 30 вопросов = 2–3 знака с максимальным словарным перекрытием
  overlap_coefficient(A, B) = |vocab(A) ∩ vocab(B)| / min(|vocab(A)|, |vocab(B)|)
  Целевое значение: ≥ 0.4
```

**Алгоритм генерации блока (жадный):**
1. Отсортировать знаки по `vocab_similarity` (перекрытие словарей)
2. Выбрать первый знак (наибольшее пересечение с базовым словарём темы)
3. Жадно добавлять следующий знак с максимальным `overlap_score` с уже выбранными
4. Остановиться когда блок содержит ≥30 вопросов

**Порядок блоков:** граф знаков, обход в ширину от «самого простого» знака (наибольшее кол-во общих слов с базовым словарём), к самому специфичному.

### Блок для Типа C (правила)

**Атомарная единица = ШАБЛОН + ЧИСЛА.**

```
Шаблонный блок (тема 11 — пример):
  Шаблоны фраз:
    «Il limite massimo di velocità...» (62×)
    «E' obbligatorio ridurre la velocità...» (23×)
    «Salvo diversa segnalazione...» (12×)

  Числовой блок:
    130 км/ч — autostrade
    110 км/ч — strade extraurbane principali (с прицепом: 80)
    90  км/ч — strade extraurbane secondarie
    50  км/ч — centri abitati
    70  км/ч — (исключения для мотоциклов и т.д.)

  Специфическая лексика:
    strade extraurbane, centri abitati, salvo diversa segnalazione,
    obbligatorio ridurre, moderare, adeguare
```

## 5. Алгоритм интервального повторения (Leitner-4)

Реализуется на `localStorage`. Простой, эффективный, не требует backend.

```
Ящик 0 (новые):    показывать сразу + в следующей сессии
Ящик 1 (видел):    показывать через 1 сессию
Ящик 2 (знаю):     показывать через 3 сессии
Ящик 3 (уверен):   показывать через 7 сессий
Ящик 4 (освоено):  review раз в 30 сессий
```

**Правила перемещения:**
- `[Знаю]` → box + 1
- `[Сложно]` → остаётся в текущем box
- `[Не знаю]` → box = max(0, box - 1)

**Схема localStorage:**
```javascript
const KEYS = {
  PROGRESS:   'qp_progress',   // существующий
  ERRORS:     'qp_errors',     // существующий
  VOCAB:      'qp_vocab',      // НОВЫЙ
  BLOCK_PROG: 'qp_block_prog', // НОВЫЙ
};

// qp_vocab
{
  "v001": { "box": 2, "seen": 5, "last_seen_block": 3 },
  "v003": { "box": 0, "seen": 1, "last_seen_block": 1 }
}

// qp_block_prog
{
  "2": {
    "current_block": 3,
    "completed_blocks": [1, 2],
    "vocab_phase_done": true
  }
}
```

## 7. Психология обучения

### Принципы (применимые к данному датасету)

**1. Паттерн-распознавание, не перевод.**  
Цель — не читать итальянский, а распознавать знакомые шаблоны. `segnale raffigurato preannuncia` встречается 278 раз — после 20 вопросов студент перестаёт читать начало фразы. Это обучающий актив.

**2. Interleaving внутри блока.**  
Перемешивать вопросы разных знаков внутри блока (не 28 вопросов знака 001, потом 24 знака 002). Снижает скорость изучения, но увеличивает долгосрочное удержание.

**3. Errorful generation.**  
Показывать итальянское слово → студент вспоминает перевод до показа. Даже при ошибке — это лучше для памяти, чем пассивное чтение.

**4. Контекстная привязка.**  
Каждое слово привязано к изображению знака. `barriere` → образ шлагбаума. Абстрактный перевод «барьеры» — хуже.

**5. Числа — отдельная карточка.**  
Для тем 11, 12, 20 числа учатся как отдельный тип карточки: шаблон с пропуском → вставить число.

### Что вызывает перегрузку → как избежать

| Проблема | Решение |
|---|---|
| Все 662 вопроса сразу | Блоки по 30 вопросов |
| Незнакомый текст с нуля | Vocab-фаза перед каждым блоком |
| Одновременно учить и тестировать | Строго разделённые фазы |
| Одинаковые вопросы подряд (один знак) | Interleaving внутри блока |
| Непонятные числа в правилах | Числовые карточки (тип C) |

## 8. NLP Pipeline (офлайн, Python-скрипт)

```
Входной текст (topic_N.json)
  ↓
Lowercase + Unicode NFC нормализация
  ↓
Сохранить акценты (è, à, ù — семантически значимы)
  ↓
Токенизация regex: [a-zàáèéìíòóùú']+
  ↓
Лемматизация: spaCy (it_core_news_sm)
  [strade → strada, veloci → veloce]
  ↓
Двухуровневая фильтрация стоп-слов:
  L1 (грамматические): il, la, di, in, un, che... → удалить из ранжирования
  L2 (квази-стопы темы): segnale, raffigurato, preannuncia → шаблонный блок
  ↓
Гибридный скоринг лексики:
  score(w, block) = 0.4 × TF_block
                  + 0.2 × TF_topic
                  + 0.3 × sign_specificity (IDF по знакам)
                  + 0.1 × false_answer_trap (бонус для слов в FALSO)
  ↓
Биграмы и триграммы (устойчивые словосочетания):
  «strada deformata», «limite massimo di velocità», «senso opposto»
  ↓
Группировка по знакам (Тип A):
  by_image = { "001.jpg": [531, 532, 534, ...], ... }
  ↓
Граф знаков (networkx):
  Ребро (знак_A, знак_B) с весом = overlap_coefficient
  Обход в ширину → порядок блоков
  ↓
Генерация topic_N_vocab.json + topic_N_blocks.json
```

### Формат topic_N_vocab.json
```json
[
  {
    "id": "v001",
    "word": "strada deformata",
    "lemma": "strada deformato",
    "translation_ru": "неровная дорога",
    "frequency": 7,
    "sign_images": ["001.jpg"],
    "example_question_id": 531,
    "semantic_group": "geometria_strada",
    "synonyms": ["pavimentazione irregolare", "strada in cattivo stato"],
    "trap_word": false,
    "level": 2
  }
]
```

### Формат topic_N_blocks.json
```json
[
  {
    "block_id": 1,
    "topic_id": 2,
    "topic_type": "A",
    "sign_images": ["001.jpg", "002.jpg"],
    "question_ids": [531, 532, 534, 560, 561, 562],
    "vocab_ids": ["v001", "v003", "v007"],
    "new_vocab_ids": ["v001", "v003"],
    "overlap_score": 0.52,
    "template_phrases": []
  }
]
```

|---|---|---|

## 14. Что НЕ делаем (и почему)

| Что | Почему |
|---|---|
| Backend / API | Не нужен для одного пользователя, localStorage достаточно |
| FSRS / Anki-алгоритм | Oверинжиниринг для MVP, Leitner-4 даёт 80% эффективности |
| TTS / аудио | Вырезано из JSON, не нужно для цели «сдать экзамен» |
| TypeScript | Добавим при переходе на backend (Phase 2) |
| Тяжёлые NLP модели на клиенте | Анализ офлайн (Python), на клиент идут только JSON |
| Tailwind / UI-фреймворк | Собственный CSS — полный контроль, iPad mini 2 |
| Анимации / transitions | Не нужны |
| Геймификация / очки / бейджи | Не нужна, личный инструмент |
| Онлайн-синхронизация | Phase 2 при переходе на backend |
